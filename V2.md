# SetupVibe 2

SetupVibe 2 is being developed on the `v2` branch. It replaces the four
scripts (`desktop.sh`, `server.sh`, `omarchy.sh` and `desktop.ps1`) with two
Bun binaries built on the [Termfy](https://github.com/promovaweb/termfy)
framework. Each binary has a TUI, a CLI and an MCP server in the same
executable.

| Binary | Edition | Systems |
| --- | --- | --- |
| `setupvibe` | Desktop: development environment, local or remote | macOS, Ubuntu, Debian, Mint, Zorin, Arch, Omarchy, Windows, WSL |
| `setupvibe-server` | Server: Docker Swarm infrastructure | Ubuntu, Debian |

The specification lives in the ClickUp document "SetupVibe 2". The SetupVibe 1
scripts stay in place on this branch until the launch, when they move to
`legacy/`.

## Layout

| Path | Content |
| --- | --- |
| `shared/core/` | Termfy core shared by both binaries: CLI, TUI, MCP, configuration, embedded docs |
| `shared/core/app/edition.ts` | Edition registry; each entry point registers its identity before the core loads |
| `shared/inventory.ts`, `shared/inventory.schema.json` | Inventory model, install resolution and JSON Schema |
| `shared/system/`, `shared/state/` | System detection, state files, run log, checksums and update check |
| `shared/commands/` | SetupVibe commands shared by both binaries: `system`, `init`, `user`, `security` |
| `shared/exec/`, `shared/install/` | Step runner with dry runs, and inventory install methods |
| `shared/init/`, `shared/users/`, `shared/security/` | init requirements and plan, user creation, security module |
| `shared/repo.ts` | GitHub URLs; every file SetupVibe 2 downloads comes from the `v2` branch |
| `shared/docs/` | Developer documentation shared by both editions |
| `shared/tests/` | Inventory, repository and Termfy core tests |
| `desktop/src/`, `server/src/` | Entry point (`main.ts`) and identity (`edition.ts`) of each binary |
| `desktop/inventory.json`, `server/inventory.json` | Official list of what each edition installs |
| `desktop/docs/`, `server/docs/` | Documentation embedded in each binary and printed by `--skill` |
| `desktop/tests/`, `server/tests/` | Edition tests |
| `desktop/bin/`, `server/bin/`, `desktop/skills/`, `server/skills/` | Helper scripts and agent skills of each edition |
| `scripts/build.ts` | Compiles both binaries |
| `version.json` | Latest and minimum version per channel, read by the update check |

Both binaries share `~/.setupvibe/` and the `SETUPVIBE_` environment prefix,
because only one of them is installed on a machine.

## Commands

```bash
bun install
bun run desktop -- --help          # run setupvibe from source
bun run server -- --help           # run setupvibe-server from source
bun test                           # every test
bun run typecheck
bun run build                      # dist/setupvibe and dist/setupvibe-server
bun run build:all                  # every platform
bun run validate                   # typecheck, tests and build
```

## Rules

- Code, identifiers, messages and JSON keys are in English. Documentation for
  people follows the repository languages.
- Every URL that points at a SetupVibe file uses the `v2` branch through
  `shared/repo.ts`. A test fails when a v2 source file points at `main` or at
  a SetupVibe 1 tag.
- The inventory files are edited by hand and validated by
  `bun test shared/tests` (see `shared/docs/inventory.md`).
- Pre-releases of the branch are tagged `v2.0.0-dev.N`.
